# hospital_managment

Hospital Management System
The Hospital Management System is a web-based application designed to streamline
hospital operations such as patient management, doctor management, appointment 
scheduling, billing, and medical records management. The system provides an 
efficient and user-friendly platform for administrators, doctors, and patients.

Technology Stack
Frontend
React.js – Building dynamic and responsive user interfaces
JavaScript (ES6+) – Client-side programming
Tailwind CSS – Modern and responsive UI styling
Backend
Python – Server-side programming language
Flask Framework – RESTful API development and business logic implementation
Database
MySQL – Relational database management system for storing application data
System Architecture
React + Tailwind CSS (Frontend)

            │ HTTP Requests (REST API)
